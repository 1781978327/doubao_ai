# 截图上传客户端使用说明
## 一、软件简介
截图上传客户端是一款支持定时截图、自定义服务器配置的工具，可自动将本地截图上传至指定服务器，同时提供无命令行窗口运行、进程伪装等功能，适用于需要远程监控或自动备份截图的场景。


## 二、环境要求
- 操作系统：Windows 10/11（64位）
- 运行依赖：无需额外安装Python环境，EXE文件可直接运行


## 三、文件结构
```
截图上传客户端/
├─ dist/                # 打包后生成的目录
│  └─ 系统助手.exe       # 主程序（可直接双击运行）
├─ screenshots/         # 本地截图临时保存目录（自动生成）
├─ send_picture.py      # 源码文件（Python开发用）
├─ screenshot_core.py   # 截图核心功能源码
├─ 系统助手.spec        # PyInstaller打包配置文件
└─ package.bat          # 一键打包脚本（Python开发用）
```


## 四、使用步骤
### 1. 运行主程序
1. 进入 `dist` 目录，双击 `系统助手.exe` 启动软件；
2. 弹出配置窗口，需填写3项核心配置（默认值可直接使用，按需修改）：
   - **服务器IP地址**：接收截图的服务器IP（例：192.168.1.6）；
   - **服务器端口**：服务器接收数据的端口（默认：7893，需与服务器端口一致）；
   - **截图间隔（秒）**：定时截图的时间间隔（默认：60秒，最小可设为1秒）。
3. 填写完成后点击「确定」，软件会最小化到系统托盘，开始自动运行。


### 2. 查看运行状态
- **系统托盘**：运行后托盘会显示“截”字图标，右键点击可选择退出软件；
- **本地截图**：截图会临时保存在 `screenshots` 目录（上传成功后不会自动删除，可手动清理）；
- **进程查看**：在任务管理器“详细信息”中，进程名为「系统助手.exe」，进程描述为“系统辅助服务”。

## 五、开发与打包（可选）
若需二次开发或重新打包，需先安装Python环境和依赖库：
### 1. 安装依赖
```bash
# 安装核心依赖
pip install pyautogui pystray pillow pywin32 pyinstaller
```

### 2. 一键打包
双击运行 `package.bat`，打包完成后会在 `dist` 目录生成新的 `系统助手.exe`，打包后的程序：
- 无命令行黑框（`--noconsole` 参数实现）；
- 单文件运行（`-F` 参数实现）；
- 自动包含所有依赖，无需额外文件。


## 六、注意事项
1. 软件运行期间需保持系统托盘常驻，关闭托盘图标会停止截图；
2. `screenshots` 目录会累积截图文件，建议定期清理以节省磁盘空间；
3. 若修改服务器配置，需重启 `系统助手.exe` 才能生效；
4. 请勿用于未经授权的监控场景，使用前需遵守相关法律法规。
